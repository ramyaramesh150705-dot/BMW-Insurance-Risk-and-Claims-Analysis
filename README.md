# BMW-Insurance-Risk-and-Claims-Analysis
BMW Insurance Risk and Claims Analysis using Power BI to explore claim trends, insurance risk patterns, and key business insights.

Project Overview
This project focuses on analysing insurance risk and claims data using Microsoft Power BI to indentify claims and claim amount.

Objectives
1. Analyse insurance claims and claim amounts.
2. Identify claim trends and risk patterns.
3. Compare claims across available categories.
4. Build an interactive dashboard for data driven decision making.
   
Tools and Technologies
1. Microsoft Power BI – dashboard creation and visualisation.
2. Microsoft Excel – data preparation and cleaning.
3. SQL – data querying.
4. Python – data analysis.

Key Dashboard Features
1. KPI cards for important insurance metrics.
2. Claim amount analysis.
3. Claims trend analysis.
4.Category-wise comparisons based on available data.
5.Interactive filters and slicers.

Project Files
1.Power BI dashboard file (.pbix).
2.Dataset (.xlsx or .csv).
3.Dashboard screenshot (.png).

Key Learnings
1.Data cleaning and preparation.
2.Data visualisation.
3.KPI analysis.
4.Interactive dashboard development.
5.Business insight presentation.
